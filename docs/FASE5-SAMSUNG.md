# Validación física pendiente

No se ha conectado un Samsung Galaxy Watch a esta entrega. Registrar modelo,
versión Wear OS, resolución, densidad, fontScale y versión de APK en cada ejecución.

| Prueba | Criterio | Estado |
|---|---|---|
| Inclinación + dedo | ejes coherentes, sin salto al soltar | No ejecutado físico |
| Pasos | total diario del proveedor, permisos y revocación | No ejecutado físico |
| Día/zona | sin total anterior ni duplicados | Unitario aprobado; físico pendiente |
| Ambiente | ningún renderizado continuo ni sensores activos | Política probada; físico pendiente |
| Batería | porcentaje del reloj y retorno correcto | API implementada; físico pendiente |
| Bisel | cualquier fila llega al centro | No ejecutado físico |
| Rendimiento | memoria y frames presentados por modelo | No ejecutado físico |
| OLED y tacto | textos legibles, brillo y zonas de toque | No ejecutado físico |

Anotar aprobado/fallido y adjuntar logs/capturas. No convertir datos del emulador
en certificación Samsung. El objetivo de 30 FPS y la tolerancia geométrica de 1 px
siguen sujetos a medición; no se aceptan por inspección del código.
